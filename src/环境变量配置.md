# 环境变量配置说明

## 前端环境变量

在项目根目录创建 `.env` 文件：

```bash
# API基础URL - Spring Boot后端地址
REACT_APP_API_BASE_URL=http://localhost:8080/api

# 文件访问URL - 用于访问上传的文件
REACT_APP_FILE_BASE_URL=http://localhost:8080/files

# WebSocket URL - 用于实时通信（如需要）
REACT_APP_WS_URL=ws://localhost:8080/ws

# 是否使用Mock数据 - 开发时可设置为true
REACT_APP_USE_MOCK=false

# 应用名称
REACT_APP_NAME=福州理工学院校友通讯网

# 应用版本
REACT_APP_VERSION=1.0.0
```

## 不同环境配置

### 开发环境 (.env.development)
```bash
REACT_APP_API_BASE_URL=http://localhost:8080/api
REACT_APP_FILE_BASE_URL=http://localhost:8080/files
REACT_APP_USE_MOCK=false
```

### 生产环境 (.env.production)
```bash
REACT_APP_API_BASE_URL=https://your-api-domain.com/api
REACT_APP_FILE_BASE_URL=https://your-file-domain.com/files
REACT_APP_USE_MOCK=false
```

### Mock模式 (.env.mock)
```bash
REACT_APP_USE_MOCK=true
REACT_APP_API_BASE_URL=http://localhost:3000/mock-api
```

## Spring Boot后端环境变量

在后端项目中配置：

### application.yml
```yaml
server:
  port: 8080

spring:
  profiles:
    active: ${SPRING_PROFILES_ACTIVE:dev}
  
  datasource:
    url: ${DATABASE_URL:jdbc:mysql://localhost:3306/fuzhou_tech_alumni}
    username: ${DATABASE_USERNAME:alumni_user}
    password: ${DATABASE_PASSWORD:your_password}
    driver-class-name: com.mysql.cj.jdbc.Driver

jwt:
  secret: ${JWT_SECRET:YourSecretKeyHereMustBeLongEnoughForHS256Algorithm}
  expiration: ${JWT_EXPIRATION:86400000}

file:
  upload-dir: ${FILE_UPLOAD_DIR:./uploads}
  max-size: ${FILE_MAX_SIZE:10MB}

app:
  cors:
    allowed-origins: 
      - ${CORS_ALLOWED_ORIGINS:http://localhost:3000,http://localhost:5173}
```

### Docker环境变量
```bash
# docker-compose.yml 或 .env 文件
DATABASE_URL=jdbc:mysql://mysql:3306/fuzhou_tech_alumni
DATABASE_USERNAME=alumni_user
DATABASE_PASSWORD=your_secure_password
JWT_SECRET=your_very_long_and_secure_jwt_secret_key_here
CORS_ALLOWED_ORIGINS=http://localhost:3000,https://your-frontend-domain.com
```

## 配置说明

### 前端配置项

| 变量名 | 描述 | 默认值 | 必需 |
|-------|------|--------|------|
| REACT_APP_API_BASE_URL | 后端API基础URL | http://localhost:8080/api | 是 |
| REACT_APP_FILE_BASE_URL | 文件访问URL | http://localhost:8080/files | 是 |
| REACT_APP_WS_URL | WebSocket URL | ws://localhost:8080/ws | 否 |
| REACT_APP_USE_MOCK | 是否使用Mock数据 | false | 否 |
| REACT_APP_NAME | 应用名称 | 福州理工学院校友通讯网 | 否 |
| REACT_APP_VERSION | 应用版本 | 1.0.0 | 否 |

### 后端配置项

| 变量名 | 描述 | 默认值 | 必需 |
|-------|------|--------|------|
| DATABASE_URL | 数据库连接URL | jdbc:mysql://localhost:3306/fuzhou_tech_alumni | 是 |
| DATABASE_USERNAME | 数据库用户名 | alumni_user | 是 |
| DATABASE_PASSWORD | 数据库密码 | - | 是 |
| JWT_SECRET | JWT密钥 | - | 是 |
| JWT_EXPIRATION | JWT过期时间(毫秒) | 86400000 | 否 |
| FILE_UPLOAD_DIR | 文件上传目录 | ./uploads | 否 |
| FILE_MAX_SIZE | 文件大小限制 | 10MB | 否 |
| CORS_ALLOWED_ORIGINS | 允许的跨域源 | http://localhost:3000 | 是 |

## 安全注意事项

1. **JWT密钥**：必须使用足够长且安全的密钥
2. **数据库密码**：使用强密码，不要在代码中硬编码
3. **CORS配置**：生产环境中限制允许的源
4. **环境文件**：不要将包含敏感信息的.env文件提交到代码仓库

## 快速配置脚本

创建 `setup-env.sh` 脚本：

```bash
#!/bin/bash

# 前端环境配置
cat > .env << EOF
REACT_APP_API_BASE_URL=http://localhost:8080/api
REACT_APP_FILE_BASE_URL=http://localhost:8080/files
REACT_APP_USE_MOCK=false
REACT_APP_NAME=福州理工学院校友通讯网
REACT_APP_VERSION=1.0.0
EOF

echo "环境变量配置完成！"
echo "请根据实际情况修改 .env 文件中的配置"
```

运行脚本：
```bash
chmod +x setup-env.sh
./setup-env.sh
```

## 验证配置

启动项目后，可以通过以下方式验证配置：

1. **检查API连接**：
   - 前端控制台无CORS错误
   - 网络面板显示正确的API请求地址

2. **检查Mock模式**：
   - Mock模式下控制台显示Mock数据提示
   - API模式下显示真实后端响应

3. **检查文件上传**：
   - 文件上传功能正常
   - 文件访问URL正确
