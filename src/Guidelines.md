# 福州理工学院校友通讯网 - 开发指南

## 项目概述

这是一个完整的校友通讯网站，包含H5移动端和管理后台，支持动态发布、评论管理、点赞功能、活动管理等。

## 界面预览说明

### 默认显示 H5 移动端
- 应用默认显示学生端H5移动界面
- 主页面路径：`/h5/personal-home`
- 所有H5页面都使用移动端布局

### 查看管理后台
- 添加URL参数 `?role=admin` 或 `?demo=admin` 查看管理后台
- 管理后台路径：`/admin/dashboard`

## 设计系统指南

### 布局原则
- H5端：最大宽度 `max-w-md`，居中显示，模拟手机界面
- 管理端：全屏布局，侧边栏 + 主内容区域
- 使用Flexbox和Grid进行响应式布局

### 颜色系统
- 主色调：`--primary: #030213` (深蓝色)
- 次要色：`--secondary: #f3f3f5` (浅灰色)  
- 强调色：`--accent: #e9ebef` (中性灰)
- 支持深色模式切换

### 字体排版
- 基础字号：16px
- 标题使用 `font-weight-medium` (500)
- 正文使用 `font-weight-normal` (400)
- 不要覆盖默认的字体大小和行高设置

### 组件规范

#### 按钮
- 主要按钮：`variant="default"` 用于主要操作
- 次要按钮：`variant="outline"` 用于辅助操作  
- 文本按钮：`variant="ghost"` 用于不重要操作

#### 卡片
- 使用 `Card` 组件包装内容区块
- 移除默认边框：`border-0 shadow-sm`
- 圆角大小：`rounded-lg`

#### 间距
- 页面内边距：`p-4`
- 组件间距：`space-y-4` 或 `gap-4`
- 小间距：`space-y-2` 或 `gap-2`

### 无障碍访问
- 所有交互元素都有适当的focus状态
- 支持键盘导航
- 包含屏幕阅读器支持
- 支持高对比度和大字体模式

### 移动端优化
- 使用安全区域：`safe-area-bottom` 等类名
- 防止输入缩放：字体最小16px
- 支持触摸友好的按钮大小（最小44px）

## 页面结构

### H5移动端 (26个页面)
主要包含：个人中心、社交功能、学校生活、生活服务、回忆录、系统功能等模块

### 管理后台 (47个页面)  
主要包含：用户管理、内容管理、数据统计、系统设置等管理功能

## 开发注意事项

1. **保持代码简洁**：优先使用现有组件，避免重复造轮子
2. **响应式设计**：确保在不同设备上都有良好体验
3. **性能优化**：使用懒加载和代码分割
4. **错误处理**：包含适当的错误边界和用户反馈
5. **可访问性**：遵循WCAG准则，支持辅助技术
